# dreamhack-writeups

드림핵(Dreamhack) 워게임 풀이를 정리한 저장소입니다.
정보보안 직무 취업을 준비하며, 문제를 풀고 분석한 과정을 기록합니다.

## 🙋 About

- 컴퓨터공학 전공, 정보보안 직무 취업 준비 중
- Burp Suite를 활용한 웹 해킹 실습 위주로 학습하고 있습니다
- 단순히 플래그를 찾는 것보다, **취약점의 원인과 실무 대응법**을 함께 정리하는 데 중점을 둡니다

## 📂 구성

| 카테고리 | 설명 |
|---|---|
| `web/` | 웹 해킹 (인증 우회, SQLi, XSS 등) |
| `system/` | 시스템 해킹 (추가 예정) |

## 📝 라이트업 목록

| 문제명 | 카테고리 | 난이도 | 핵심 취약점 | 링크 |
|---|---|---|---|---|
| cookie | web | B4 (입문) | 클라이언트 쿠키 값 기반 인증 (세션 미검증) | [cookie.md](./web/cookie.md) |

## ✍️ 라이트업 작성 형식

각 문제 풀이는 아래 구조로 정리합니다.

1. **문제** — 문제 설명 및 목표
2. **풀이과정** — 분석 흐름, 시도한 접근, Burp Suite 캡처
3. **취약점 정리** — 근본 원인과 실무에서의 올바른 대응법

> 플래그 값은 공개하지 않으며, 풀이 과정과 원리 설명 위주로 작성합니다.
